# Window switcher

What: a prefix (for example `w text`) lists the open top-level windows by title and
program, and Enter brings the chosen one to the front.

Why: Keypirinha and Listary offer it, and PowerToys Run has the Window Walker plugin. For
keyboard users it replaces Alt+Tab when many windows are open. It is medium effort,
because windows must be listed through native calls and the list must stay fast.
