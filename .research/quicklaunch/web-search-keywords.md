# Web search keywords

What: user-defined keywords that turn the rest of the query into a search URL, for example
`g text` -> Google, `yt text` -> YouTube, `wiki text` -> Wikipedia. Each keyword is a
template with a placeholder for the text, edited in the settings. A few defaults are
included. A source shortcut letter with the same name wins, as with "web".

Why: custom web searches are a core feature of Wox and Flow Launcher and one of their most
used plugins. "web"/"//" already opens URLs, so this extends a mode that already exists.
