# Unit conversion

What: the calculator also understands `<number> <unit> in <unit>` for length, weight,
temperature, volume, data size and time, for example `10 km in mi` or `30 c in f`. The
result goes to the clipboard like any other result. Currency is left out, because it
would need an online rate service.

Why: unit conversion is a common request for Flow Launcher (the General Converter plugin)
and PowerToys Run. The calculator row already exists, so it is a natural extension. It is
medium effort because of the unit table.
