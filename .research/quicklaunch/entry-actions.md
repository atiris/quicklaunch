# Entry actions

What: extra keys on the selected entry:
- Ctrl+Shift+Enter starts it as administrator
- Ctrl+Enter opens the folder that contains it, with the file selected; for a shortcut,
  the folder of its target
- Ctrl+C copies its full path when the search box has no selected text

The hint line names the keys.

Why: run as administrator and "open containing folder" are standard in Flow Launcher,
PowerToys Run and Keypirinha, and among the most requested actions. Shift+Enter is already
taken by parameters, so these keys fit the same pattern.
