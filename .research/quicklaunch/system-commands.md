# System commands

What: built-in entries that are found by typing, like any other entry: Lock, Sleep, Restart,
Shut down, Sign out, Empty recycle bin, and the common Windows settings pages
(display, sound, Bluetooth, Wi-Fi, apps, Windows Update) via `ms-settings:` links.
Commands that end the session ask for confirmation.

Why: Flow Launcher and PowerToys Run ship these out of the box, and users expect them in
any launcher. Today the user has to create a shortcut file for each one. They are small,
fixed entries, so they cost nothing at search time.
